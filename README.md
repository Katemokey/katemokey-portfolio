# Kate Mokey — интерактивные демо

Репозиторий для учебных веб-проектов из портфолио [Kate Mokey](https://katemokey.ru/).

- **Rechka** — [открыть сайт](https://katemokey.github.io/katemokey-portfolio/rechka/) · [посмотреть макет в Figma](https://www.figma.com/design/3nyh3Cf0qoh4NqxxoilKyq?node-id=15-3).

Сайт Rechka — учебная демонстрация. Данные специалистов иллюстративные, форма не отправляет реальные заявки.

Для публикации GitHub Pages выберите ветку `main` и папку `/docs` в **Settings → Pages**.
